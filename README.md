# 🐱 냥이 여행 가이드

Groq AI로 동작하는 해외여행 가이드 챗봇이에요. 카카오톡처럼 대화하는 모바일 앱 화면으로 만들었고, `index.html` 파일 하나로 실행돼요.

## 할 수 있는 일

- 일정 짜기: "3박4일 일본 일정 알려줘"
- 날씨와 옷차림: "12월 뉴욕 날씨에 맞는 옷 추천해줘"
- 맛집, 관광지, 교통, 환전, 입국 준비, 짐 체크리스트
- 답변을 실시간으로 받아 보기 (스트리밍)
- 답변마다 여행지 사진 (위키백과 대표 사진)
- 답변마다 다음 행동 버튼 3개 (항공권, 숙소, 상세 일정 등)
- 하단 예시 질문 칩 (2단), 새 대화(✨) 시 다시 표시

## 실행 방법

1. `index.html`을 크롬 같은 브라우저로 열어요.
2. 처음 뜨는 시트에 Groq API 키(`gsk_...`)를 입력하고 **저장하고 시작하기**를 눌러요. 키는 [console.groq.com/keys](https://console.groq.com/keys)에서 발급받아요.
3. 대화를 시작해요.

설치, 빌드, 서버는 필요 없어요. 인터넷 연결만 있으면 돼요.

## API 키 처리

- 키는 코드에 들어 있지 않아요. 사용자가 브라우저에서 직접 입력해요.
- 입력창은 비밀번호 형태로 가려지고, 👁️ 버튼으로 잠깐 볼 수 있어요.
- 기본은 이 기기 브라우저에 저장하고, "이 기기에 키 기억하기"를 끄면 탭을 닫을 때 삭제돼요.
- 키는 Groq API(`api.groq.com`)로만 전송돼요.
- 설정(⚙️)에서 저장된 키를 바로 삭제할 수 있어요.
- 본인 키를 `index.html`에 직접 적어서 배포하지 마세요. 코드를 볼 수 있는 사람은 누구나 가져다 쓸 수 있어요.

## 모델

키를 저장할 때 Groq에서 지금 쓸 수 있는 모델 목록을 받아와 선택창을 채워요. 저장해 둔 모델이 없어지면 사용 가능한 모델로 자동으로 바꿔요.

## 답변에 사진과 버튼이 붙는 방식

시스템 프롬프트가 냥이에게 답변 마지막 줄에 아래 형식의 메타 정보를 붙이게 해요. 화면에는 이 줄이 보이지 않아요.

```
[[META]]{"place":"도쿄","wiki":"Tokyo","actions":[{"label":"✈️ 비행기 예매하러 가기","type":"flight"},{"label":"📅 상세 일정 보기","type":"ask","prompt":"..."},{"label":"🏨 숙소 보러 가기","type":"hotel"}]}
```

- `wiki`: 영어 위키백과 문서 제목. 이 제목으로 대표 사진을 가져와요.
- `actions[].type`
  - `flight`: Google Flights 검색을 새 탭으로 열어요.
  - `hotel`: Booking.com 검색을 새 탭으로 열어요.
  - `ask`: `prompt` 내용을 질문으로 대신 보내 대화를 이어가요.
- 메타 정보가 없거나 형식이 틀리면 기본 버튼 3개(더 자세히, 현지 꿀팁, 준비물)가 나와요.

실제 서비스 앱에 붙일 때는 `runAction` 함수에서 항공권과 숙소 링크를 그 앱의 예매 페이지 주소로 바꾸면 돼요.

## 배포 (GitHub Pages)

1. [github.com/new](https://github.com/new)에서 Public 저장소를 만들어요.
2. **uploading an existing file**로 `index.html`을 올리고 Commit해요.
3. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save해요.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/`으로 접속해요.

파일을 고친 뒤에는 `index.html`을 같은 방법으로 다시 올려야 배포 주소에 반영돼요. Netlify Drop([app.netlify.com/drop](https://app.netlify.com/drop))에 폴더를 끌어다 놓는 방법도 있어요.

## 알려진 한계

- 배포한 주소를 여는 사람은 각자 자기 Groq 키를 입력해야 해요. 키 없이 모두가 쓰게 하려면 키를 숨겨 두는 중계 서버가 필요해요. 서버에는 요청 횟수 제한을 꼭 걸어야 해요.
- 대화 내용은 저장하지 않아서 새로고침하면 사라져요.
- 비자 규정, 가격, 운영시간 같은 정보는 바뀔 수 있어서 출발 전 공식 사이트에서 확인해야 해요.
